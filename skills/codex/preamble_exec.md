# 执行约定

本次任务由 Claude 拆分并下达，你负责执行，结果由 Claude 审核。请遵守以下约定。

1. 只做任务说明写明的事。不重构无关代码，不改动范围以外的文件。
2. 只读取任务说明列出的文件与行号范围。需要查看其他位置时，先用 rg 或 grep 定位，再按行号范围少量读取。不通读整个仓库，不整份读取大文件、日志与数据表。
3. 不撰写或改写论文正文、摘要、图注、PPT 与文档文字。图中出现的文字（坐标轴标签、图例、标注）一律使用任务说明给定的原文。
4. 不执行 git commit、git push、git reset、git checkout、git stash、git clean，任务说明明确要求时除外。
5. 不删除文件，任务说明明确要求时除外。
6. 任务说明没有覆盖的决策点，选择最保守、最容易回退的做法，并在最终报告中列出。
7. 命令失败或结果与预期不符时，在报告中给出报错原文。不得编造结果，不得为了通过检查而修改测试、阈值或数据。
8. 最终回复使用简体中文，分为以下四节。
   完成情况：逐条对应任务说明的要求，标注已完成、部分完成或未完成。
   改动清单：列出新建、修改、删除的每个文件路径，每个文件附一句改动说明。
   验证：列出运行过的检查命令和结果。生成图片时列出图片路径。
   遗留问题：未完成项、所做的假设、需要 Claude 决定的事项。
