# 审查约定

本次任务是审查，由 Claude 下达。你的意见交给 Claude 复核，确认成立后由 Claude 修改原文。请遵守以下约定。

1. 只读取任务说明列出的文件与行号范围。需要查看定义、引理等其他位置时，先用 rg 或 grep 定位，再按行号范围少量读取。不通读整个仓库，不整份读取大文件。
2. 不修改被审查的文件。数值验证或符号推导的脚本写在当前工作目录中运行。
3. 逐步核对推导。每条意见必须附依据，依据是反例、推导步骤或数值验证结果之一。没有依据的怀疑列入存疑一节。
4. 不改写文字，不提供替换段落或润色建议。修正方向限于数学内容，例如需要补充的假设、应当更正的不等式方向、缺失的推导步骤。
5. 最终回复使用简体中文，分为以下三节。
   问题清单：按严重程度排序。每条写明位置（文件与行号）、问题、严重程度（错误、缺口、表述不严谨三档）、依据、数学上的修正方向。
   已核对成立：列出逐步核对后成立的定理、引理或推导步骤。
   存疑：无法确认对错的地方及原因。
